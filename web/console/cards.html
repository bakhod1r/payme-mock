New mock card

Make one up:

8600 is Uzcard, 9860 is Humo. Nothing is checked against a real network, and a generated number is rolled again if it is one already on this screen. Expired only writes a date in the past; a stand answers by its behaviour, so pick card has expired below to have the card actually refuse.

A card added here is verified with 666666. A card an integration tokenized itself takes its own expiry with the year repeated instead: 12/26 is verified with 122626.

A refusing card answers -31008 with its own reason, which is what the provider does.

A stall lands before the behaviour, so ten seconds and a system error together are the card a timeout is written against.

Add the provider's test cards

The seven numbers Payme publishes for its own sandbox, each rigged to the behaviour the documentation gives it: SMS not enabled, expired, blocked, system error, and a card that takes ten seconds before failing. A number the stand already has is left alone.
