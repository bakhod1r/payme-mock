Playground

The Subscribe API, running in this tab. It is the same Go service the stand runs — the same domain, the same JSON-RPC handler — compiled to WebAssembly and wired to memory instead of Postgres. Nothing is sent anywhere.

What this is not: there is no merchant behind it, so the Merchant API chain is accepted rather than really driven; there is no worker, so a payment settles at once instead of walking its states; and there is no database, so a reload starts over. Everything else is the real thing — including which methods the browser credential is allowed to call.
